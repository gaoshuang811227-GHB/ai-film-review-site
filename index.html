AI Film Review

AI Film Review is an internal media review utility used by AI Film Company workflows.

The application uses Google Drive only to transfer specific video and audio files created by the application or explicitly authorized for use with it. Its access is limited to the drive.file scope. It does not request access to search, read, or manage the user's entire Google Drive.

What the workflow does

  • Uploads specific review media.
  • Retrieves the same media by its exact Google Drive file ID.
  • Checks file identity and integrity using size and SHA-256.
  • Makes authorized media available to an internal review workflow.

OAuth client credentials and user authorization tokens used by the local Runner are stored outside the source repository. On Windows, locally stored credentials and tokens are protected with CurrentUser DPAPI.
